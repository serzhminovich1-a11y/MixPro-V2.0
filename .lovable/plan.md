# Coach marks + tutorial перед тренировками

Каждая игра будет открываться коротким объяснением: **что услышать**, **куда нажимать**, **как считаются очки**. Первый заход — авто-показ, потом кнопка «?» в шапке всегда рядом.

## Что увидит пользователь

1. Открывает игру, например `/games/frequency`.
2. Поверх экрана появляется карточка-туториал (3 шага + строка «Слушай: …» + Pro-tip).
3. Кнопка **«Начать»** → закрывает туториал и показывает обычный выбор режима (Practice / Ranked).
4. В шапке рядом с заголовком — иконка **?**. Клик = снова открыть туториал. Флажок «больше не показывать» сохраняется в localStorage per-game, так что при повторных заходах туториал не мешает, но всегда доступен.

Пример карточки (EQ Peak):

```text
┌───────────────────────────────────────────────┐
│ TUTORIAL · EQ PEAK                        [x] │
│                                               │
│  Цель: угадать поднятую частоту               │
│                                               │
│  ① Нажми «Играть» — услышишь материал с       │
│     Bell-подъёмом на одной полосе             │
│  ② Води мышью по EQ-графику — сравнивай       │
│     на слух                                   │
│  ③ Кликни по нужной частоте, чтобы ответить   │
│                                               │
│  🎧 Слушай: где звук «выпирает», становится   │
│    ярче или гуднее остального                 │
│                                               │
│  💡 Совет: держи ПКМ для A/B сравнения        │
│                                               │
│     [ Начать тренировку ]   ☐ Больше не       │
│                               показывать      │
└───────────────────────────────────────────────┘
```

Визуально — та же тёмная панель + mint-акценты + fade-in анимация, что и в остальных карточках. `prefers-reduced-motion` уважается.

## Что добавляем

- **`src/lib/games/tutorials.ts`** — словарь на 14 игр:
  `{ goal, listenFor, steps: string[], tip?, sensory? }`.
  Тексты пишу отдельно под каждый тренажёр (частота / cut / фильтр / dB / pan / три компрессора / sandbox / distortion / delay / reverb / pitch shift).
- **`src/components/games/how-to-play.tsx`** — компонент с оверлеем-модалкой:
  numbered steps, «Слушай:» строка, tip, кнопка Start, checkbox «не показывать».
  Управляется через prop `open` + `onClose`.
- **Правки в `src/components/games/game-frame.tsx`**:
  - `GameFrame` принимает новый опциональный prop `gameId: string`.
  - В шапке рядом с тегом появляется маленькая кнопка **?** (иконка `HelpCircle`).
  - Внутри `GameFrame` хук `useTutorial(gameId)`, который на mount читает `localStorage.mixpro.tut.<gameId>` и, если пусто, показывает `<HowToPlay>` автоматически. `?` открывает модалку вручную.
- **14 game-роутов**: в каждый `<GameFrame …>` дописать `gameId="frequency"` / `"eq-cut"` / … . Никакой другой логики не трогаем.

## Технические детали

- Оверлей — тот же `.panel` стиль, backdrop-blur, focus-trap не нужен (кнопка Start и Esc закрывают).
- Esc → закрыть; клик по backdrop → закрыть; при закрытии, если чекбокс отмечен → `localStorage.setItem`.
- SSR-safe: чтение localStorage только внутри `useEffect`; исходное состояние `open=false`, после mount выставляется корректное.
- Автопоказ срабатывает **до** `ModePicker` (модалка над всей игрой), поэтому не ломает существующую логику раундов/аудио.
- Ключ хранилища: `mixpro.tut.<gameId>`; значение `"1"` = «не показывать снова». Легко сбросить одним `localStorage.clear()`.
- Ноль изменений в бэкенде, аудио-движке, БД. Только UI/презентация.
